# ProyectoFinal Front# 🧠 Aplicación de generar rutinas
Parte front de la aplicación web para gestionar intereses, objetivos, tareas y rutinas semanales.  

---  
## 🚀 Instalación  
### Frontend   
 
1. `npm install`  
2. `ng serve` → http://localhost:4200  

---  
## 🧠 Funcionalidades  
### 🔐 Autenticación  
- Registro con: nombre, email, teléfono, contraseña  
- Login con JWT  

### 📌 Jerarquía  
1. **Intereses** (⭐)  
- Crear/eliminar  
- Ver objetivos asociados  

2. **Objetivos** (🎯)  
- Crear/eliminar por interés  
- Ver tareas asociadas  

3. **Tareas** (📋)  
- Crear/eliminar por objetivo  

4. **Rutinas** (🗓️ )  
- Asignar tareas a días/horas  
- Visualización semanal
